## 版本二：60秒 产品介绍款（适合B站/知乎视频/技术社群）

> 【场景：先痛点引入，再演示操作，最后展示成品效果】

**口播：**

你是不是也遇到过这种场景——要把行情数据从各种 API 拉到本地数据库，每天写一堆 Python 脚本，处理分页、重试、异常、入库，改了又改，烦不胜烦？

我做一个免费工具给大家——金智汇连ETL。

它是什么？一个跨平台的可视化数据同步工具。你只需要在画布上拖拽节点、连线，就能搭建完整的数据采集清洗入库流程。

来看几个核心能力：

**第一，数据源丰富。** 内置 AKShare、通达信本地文件、Tushare、Binance、Yahoo Finance、Mootdx 等多个数据源适配器，还支持 CSV、Excel、JSON、Parquet 文件读取和通用 HTTP 接口。

**第二，数据清洗强大。** 去重、空值处理、列运算、条件过滤、范围控制、分组排序、K线重采样、技术指标计算——全部可视化配置，零代码。

**第三，多目标写入。** MySQL、PostgreSQL、DuckDB、SQLite、ClickHouse，甚至支持文件导出和 Excel 写入。

**第四，生产级调度。** APScheduler 定时任务，支持断点续传、失败自动重试、事务保障、完整运行日志。

**第五，自定义脚本。** 支持 Python 自定义节点，高级沙箱可以导入任意第三方库，灵活度拉满。

最关键是——不绑定任何第三方私有协议，完全合规安全。你自主对接数据源，工具只做数据处理载体。

Windows 下一个 start.bat 直接启动，不需要配环境、装依赖。

> 【场景：故事引入 + 实机演示 + 对比竞品 + CTA】

**口播：**

给大家讲个真实场景。我一个做量化的朋友，每天需要从 Tushare 拉行情数据，存到本地 DuckDB 做回测。他之前自己写 Python 脚本，搞了两天——分页处理、异常重试、字段映射、数据入库，写完发现还得做定时调度。

后来我给他用了金智汇连ETL，5分钟拖了几个节点，连线搞定。

它长什么样？打开是一个类似流程图的编辑器，左边是节点列表：数据源节点、清洗节点、计算节点、写入节点。拖到画布上连线，配置参数，点运行就行。

支持哪些数据源？AKShare 免费A股行情、通达信本地K线文件、Tushare SDK、Binance 加密货币行情、Yahoo Finance 全球市场、Mootdx 通达信私有协议，还有 CSV、Excel、JSON、Parquet 文件读取。后续还会支持更多通用 HTTP 接口，几乎什么数据都能接。

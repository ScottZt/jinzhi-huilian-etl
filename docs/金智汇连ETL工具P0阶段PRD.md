金智汇连 ETL 第一阶段 P0 级功能用户故事
文档说明
本文档仅聚焦第一阶段（0-3 个月）P0 级功能（最高优先级，决定产品基础可用性），覆盖数据源管理、可视化工作流、数据落地、AI 辅助 4 大核心模块。
用户角色统一聚焦核心目标用户：个人量化交易者（新手 / 初级从业者，无专业 ETL 开发基础，核心需求是快速处理量化行情数据，用于策略回测）。
每个用户故事遵循「角色 - 场景 - 需求 - 期望」四要素，贴合实际使用场景，明确验收边界，方便开发对接、测试验证。
一、数据源管理模块（P0 级功能）
1.1 合规量化数据源接入（P0）
用户故事 1：Tushare 数据源连接
角色：个人量化交易者（新手）
场景：我想获取 A 股日线行情数据用于策略回测，已知自己有 Tushare 的 API 密钥，之前用 Python 手动拉取数据很繁琐，希望通过工具快速连接获取数据。
需求：工具内置 Tushare 数据源接口，我能输入自己的 API 密钥，选择股票标的、时间周期（日线），一键测试连接，连接成功后可拉取对应数据。
期望：
数据源列表中能直接找到 “Tushare” 选项，无需手动配置接口地址；
密钥输入框有加密显示（隐藏输入内容），提交后有 “测试连接” 按钮，连接成功 / 失败有明确提示；
连接成功后，可通过搜索股票代码 / 名称筛选标的，选择时间范围（如近 1 年），一键拉取数据，拉取过程有进度提示；
首次使用该数据源时，弹出合规提示（明确数据仅限个人使用，不可用于商业分发），确认后才可继续操作，提示不可跳过。
用户故事 2：期货 CTP 行情数据源连接
角色：个人量化交易者（初级）
场景：我做期货量化交易，需要获取期货主力合约的分钟线数据，之前手动对接 CTP 接口复杂，希望工具能简化连接流程，快速拉取合规行情数据。
需求：工具内置期货 CTP 合规数据源接口，我能输入 CTP 账号、密码等必填参数，测试连接成功后，筛选期货品种、合约类型，拉取对应分钟线数据。
期望：
数据源分类清晰，期货类数据源单独分组，能快速找到 “CTP 行情”；
参数配置界面仅显示必填项（账号、密码、服务器地址），有默认服务器地址可选，减少配置成本；
测试连接失败时，提示具体错误原因（如账号密码错误、网络问题），方便排查；
拉取数据时，可选择 1min/5min 等常用周期，支持多合约同时拉取。
用户故事 3：自定义 HTTP/API 数据源配置
角色：个人量化交易者（初级）
场景：我有一个第三方量化数据源的 API 接口（非内置数据源），希望能将其接入工具，统一处理数据，不用切换多个工具。
需求：工具支持自定义 HTTP/API 数据源配置，我能填写接口地址、请求方式、请求参数、密钥，测试连接成功后，拉取接口返回的量化数据。
期望：
有 “自定义数据源” 入口，配置界面简洁，支持 GET/POST 两种请求方式；
可填写请求头、请求参数，支持参数占位符（如时间范围参数），方便灵活配置；
测试连接后，可预览接口返回的数据，自动识别数据格式（JSON/CSV），提取量化相关字段（如标的代码、时间、收盘价）；
自定义数据源可保存，后续无需重复配置。
1.2 本地文件数据源导入（P0）
用户故事 4：CSV/Excel 量化数据批量导入
角色：个人量化交易者（新手）
场景：我之前手动下载了多支股票的日线行情数据，保存为 CSV 格式，现在想将这些本地文件导入工具，进行统一清洗处理，不用手动逐个处理文件。
需求：工具支持单文件 / 多文件批量导入，能自动识别 CSV/Excel 文件的表头和数据格式，导入后可预览数据。
期望：
有 “导入本地文件” 按钮，支持选择单个文件或多个文件（按住 Ctrl 多选）；
导入时自动识别表头（如 “code”“date”“open”“close”），无需手动映射字段；
导入后可预览前 100 行数据，能清晰看到标的代码、时间、行情数据等核心字段，确认数据无误后再进入下一步处理；
支持导入多个不同标的的文件，导入后可按标的分类展示，方便后续批量处理。
二、可视化工作流模块（P0 级功能）
2.1 基础数据处理节点（P0）
用户故事 5：缺失值填充与异常值剔除
角色：个人量化交易者（新手）
场景：我拉取的 A 股日线数据中，有部分日期的成交量、收盘价数据缺失，还有个别异常值（如涨跌停异常波动），这些数据会影响回测结果，希望能快速清洗这些数据。
需求：工具提供缺失值填充、异常值剔除节点，我能拖拽节点到工作流，配置填充规则（如用前一天数据填充）、异常值判断标准（如偏离均值 3 倍标准差），运行节点后完成数据清洗。
期望：
基础清洗节点分类清晰（如 “数据清洗” 分组下可找到缺失值填充、异常值剔除节点）；
节点拖拽流畅，可与数据源节点连线，配置界面有简单易懂的说明（如填充规则选项：前向填充、后向填充、均值填充）；
运行节点后，可预览清洗后的数据，清晰看到缺失值、异常值已被处理，同时有清洗日志（如 “填充缺失值 12 条，剔除异常值 3 条”）；
配置参数可保存，后续处理同类数据可直接复用。
用户故事 6：字段筛选与重命名
角色：个人量化交易者（新手）
场景：我拉取的数据源包含很多无关字段（如 “换手率”“市盈率”），而我回测只需要 “标的代码、日期、开盘价、收盘价、成交量” 这 5 个字段，同时希望将字段名简化（如 “open” 改为 “开盘价”），方便后续查看。
需求：工具提供字段筛选、字段重命名节点，我能选择需要保留的字段，修改字段名称，运行节点后得到简化后的数据集。
期望：
字段筛选节点支持勾选需要保留的字段，未勾选字段自动剔除；
字段重命名节点可批量修改字段名，输入新名称后实时预览效果；
运行节点后，预览数据仅显示筛选后的字段，字段名与修改后一致，无遗漏、无错误；
支持保存筛选、重命名规则，后续处理同类数据可直接调用。
2.2 量化核心基础节点（P0）
用户故事 7：股票复权处理（前复权 / 后复权）
角色：个人量化交易者（初级）
场景：我拉取的股票行情数据是未复权的，直接用于策略回测会导致价格偏差，影响回测准确性，希望工具能快速完成复权处理，无需手动计算。
需求：工具提供复权处理节点，我能选择前复权 / 后复权方式，运行节点后自动完成数据复权，复权结果准确。
期望：
复权节点参数简单，仅需选择复权类型（前复权 / 后复权），无需配置复杂参数；
运行复权后，可预览复权前后的价格对比（如收盘价差异），确认复权效果；
复权逻辑准确，与东方财富、同花顺等主流行情软件的复权数据一致，无偏差；
复权后的数据集可直接用于后续指标计算、导出。
用户故事 8：涨跌停 / 停牌数据标记
角色：个人量化交易者（初级）
场景：我做趋势策略回测，需要排除停牌、涨跌停期间的数据，避免回测结果失真，希望工具能自动标记这些特殊数据，方便后续筛选剔除。
需求：工具提供涨跌停、停牌数据标记节点，运行节点后，自动在数据集中新增 “涨跌停标记”“停牌标记” 字段，标记对应数据行。
期望：
节点无需复杂配置，默认按 A 股涨跌停规则（主板 ±10%，ST±5%）自动判断，支持手动调整涨跌停比例；
标记字段清晰（如 “涨跌停标记” 取值为 “涨停”“跌停”“无”，“停牌标记” 取值为 “是”“否”）；
标记逻辑准确，能正确识别停牌、涨跌停数据，与行情软件一致；
标记后的数据可直接用于后续筛选节点，快速剔除停牌、涨跌停数据。
用户故事 9：周期转换（日线 / 分钟线）
角色：个人量化交易者（初级）
场景：我拉取的是股票 1min 分钟线数据，而我的策略是日线级别回测，需要将分钟线数据转换为日线数据（如开盘价取当日第一根分钟线开盘价，收盘价取当日最后一根分钟线收盘价），希望工具能自动完成转换。
需求：工具提供周期转换节点，我能选择源周期（1min）、目标周期（日线），运行节点后自动完成数据聚合，生成目标周期数据。
期望：
周期选项包含常用量化周期（1min、5min、15min、30min、日线），可自由选择源周期和目标周期；
数据聚合逻辑准确（如日线开盘价 = 当日第一根分钟线开盘价，收盘价 = 当日最后一根分钟线收盘价，成交量 = 当日分钟线成交量总和）；
转换后的数据无缺失、无重复，时间戳格式统一（如日线数据时间为 YYYY-MM-DD）；
支持多标的同时进行周期转换，提升处理效率。
用户故事 10：简单均线指标计算
角色：个人量化交易者（新手）
场景：我做均线交叉策略回测，需要计算股票的 5 日均线、10 日均线数据，希望工具能直接生成均线指标，无需手动编写公式。
需求：工具提供均线指标计算节点，我能选择均线周期（如 5 日、10 日），运行节点后自动在数据集中新增均线字段（如 “MA5”“MA10”）。
期望：
均线周期支持自定义（可输入任意整数，如 5、10、20），支持同时计算多个均线周期；
均线计算逻辑准确（如 MA5 = 近 5 日收盘价平均值），与主流行情软件一致；
新增的均线字段清晰标注，与原有行情数据对应，无错位；
均线数据可直接用于后续策略回测数据导出。
2.3 工作流基础操作（P0 补充，支撑核心流程）
用户故事 11：工作流保存与加载
角色：个人量化交易者（新手）
场景：我花了 10 分钟搭建了一个 “数据源拉取→复权处理→均线计算” 的工作流，希望能保存下来，后续处理同类数据时不用重新搭建，节省时间。
需求：工具支持工作流本地保存，保存后可随时加载使用，保存的工作流包含所有节点配置和连线逻辑。
期望：
有 “保存工作流”“加载工作流” 按钮，保存时可自定义工作流名称（如 “A 股日线均线处理”），选择保存路径；
保存后，工作流文件可在本地文件夹找到，支持复制、备份；
加载工作流时，可快速找到保存的文件，加载后所有节点、配置、连线与保存时一致，无需重新配置；
支持同时保存多个工作流，方便区分不同处理场景。
用户故事 12：单节点试运行
角色：个人量化交易者（新手）
场景：我搭建了一个包含多个节点的工作流，担心整个流程运行出错后难以排查问题，希望能单独运行某个节点，查看该节点的处理结果，逐步调试。
需求：工具支持单节点试运行，选中某个节点后，可单独运行该节点，查看中间处理数据，排查节点配置问题。
期望：
选中节点后，右键有 “单独运行” 选项，运行后弹出该节点的处理结果预览窗口；
单节点运行仅处理该节点的逻辑，不影响其他节点，运行日志清晰显示节点处理情况（如 “运行成功，处理数据 1000 条”）；
若节点运行失败，提示具体错误原因（如参数配置错误、数据格式异常），方便快速修改；
单节点运行后的中间数据可预览、可导出，便于核对处理逻辑。
三、数据落地模块（P0 级功能）
3.1 存储格式适配（P0）
用户故事 13：导出为回测框架适配格式（Backtrader/VNPY）
角色：个人量化交易者（初级）
场景：我完成了数据清洗、指标计算后，需要将数据导出，用于 Backtrader 策略回测，之前手动调整数据格式很耗时，希望工具能直接导出符合回测框架要求的格式。
需求：工具支持直接导出适配 Backtrader、VNPY 框架的数据格式，导出后无需二次修改，可直接导入回测框架。
期望：
导出选项中明确标注 “Backtrader 适配格式”“VNPY 适配格式”，可直接选择；
导出的文件格式（如 CSV/Parquet）、字段顺序、字段名称与回测框架要求完全一致（如 Backtrader 要求的 “datetime”“open”“high”“low”“close”“volume” 字段）；
导出时可选择导出路径、自定义文件名，导出过程有进度提示，导出完成后提示 “导出成功，可直接导入回测框架”；
导出的数据无格式错误、无数据缺失，导入回测框架后可正常运行。
用户故事 14：导出为轻量化存储格式（DuckDB/SQLite）
角色：个人量化交易者（初级）
场景：我处理完成的量化数据较多，希望保存为轻量化、查询速度快的存储格式，方便后续随时调用、查询，避免占用过多磁盘空间。
需求：工具支持导出为 DuckDB、SQLite 轻量化存储格式，导出后可直接用于本地查询、后续数据处理。
期望：
导出格式选项中包含 DuckDB、SQLite，可自由选择；
导出过程快速，大数据量导出无卡顿，导出的文件体积适中；
导出的数据库文件可直接用对应工具（如 DuckDB CLI）打开查询，数据完整、无损坏；
导出时可选择数据表名称，方便后续区分不同数据集。
四、AI 辅助模块（P0 级功能）
4.1 基础脚本生成（P0）
用户故事 15：自然语言生成量化数据处理 Python 脚本
角色：个人量化交易者（新手）
场景：我不懂复杂的 Python 编程，希望能通过输入简单的文字需求，生成量化数据处理脚本，用于手动运行或后续修改，节省编程时间。
需求：工具支持输入自然语言指令，自动生成对应的 Python 量化数据处理脚本，生成的脚本可复制、本地保存，能直接运行。
期望：
有 AI 脚本生成入口，输入框有提示（如 “请输入需求，例：拉取贵州茅台近 1 年日线数据，进行前复权处理，计算 5 日均线”）；
输入需求后，点击 “生成脚本”，快速生成 Python 脚本，脚本包含完整的代码逻辑（如数据源连接、数据拉取、复权、均线计算）；
生成的脚本无语法错误，可直接运行，运行结果与需求一致；
支持脚本复制到剪贴板、本地保存为.py 文件，方便后续使用、修改。
4.2 本地大模型适配（P0 补充，保障隐私）
用户故事 16：接入本地 Ollama 大模型生成脚本
角色：个人量化交易者（初级）
场景：我处理的量化数据包含自己的策略相关信息，担心使用云端大模型会泄露数据隐私，希望能接入本地部署的 Ollama 大模型，在本地生成脚本。
需求：工具支持配置本地 Ollama 大模型端口，接入后，AI 脚本生成过程在本地运行，数据不上传云端。
期望：
有 “本地大模型配置” 入口，可输入 Ollama 模型的本地端口、模型名称（如 “llama3”）；
配置完成后，点击 “测试连接”，可验证本地模型是否能正常调用；
调用本地模型生成脚本时，无数据上传提示，生成速度与本地模型性能匹配；
生成的脚本逻辑、质量与云端模型一致，可直接运行。
五、用户故事通用验收标准
所有用户故事对应的功能，操作流程简单易懂，新手可独立完成，无需专业技术基础；
功能运行无致命 BUG，数据处理准确率 100%，与主流行情软件、回测框架数据一致；
操作过程有清晰的提示（如连接成功、运行完成、错误原因），用户可快速定位问题；
所有功能均支持本地运行，数据不上传云端，保障用户数据隐私；
界面交互流畅，无卡顿、无样式错乱，适配 Windows10 及以上系统。

# AI交互式辅助-页面交互原型清单（P0）

## 1. 目标
- 覆盖 `凭证`、`数据源`、`连接管理`、`工作流` 四类高频场景。
- 通过“分步引导 + 快捷动作 + 故障排查”降低首次使用门槛。
- 与现有弹窗和流程保持一致，不引入重型新页面。

## 2. 原型清单

### 2.1 全局入口（列表页）
- 位置：`凭证管理`、`数据源`、`工作流` 顶部工具栏。
- 控件：`🤖 AI 辅助` 按钮。
- 行为：
  - 点击后打开统一 `AI 交互式助手` 弹窗。
  - 默认模式为“新手引导”。
  - 当前场景自动带入（credential/datasource/workflow）。

### 2.2 表单内入口（新建/编辑弹窗）
- 位置：`新建连接`、`新建凭证`、`新建数据源` 弹窗 footer。
- 控件：`🤖 AI 辅助` 按钮（与“保存/预览”同级）。
- 行为：
  - 自动读取当前弹窗已填写字段作为上下文。
  - 生成“步骤 + 自检清单 + 快捷动作”建议。
  - 快捷动作可一键回填字段（如默认端口、默认 base_url）。

### 2.3 故障兜底入口（测试失败后）
- 位置：`凭证测试失败`、`连接测试失败`后的确认框。
- 行为：
  - 选择“是”后自动打开 AI 助手。
  - 助手模式切为“故障排查”。
  - 自动写入最近错误信息并立即生成建议。

### 2.4 AI 交互式助手弹窗（统一组件）
- 标题：`🤖 AI 交互式助手`。
- 字段：
  - `辅助模式`：新手引导 / 故障排查
  - `你的目标`：自然语言输入
  - `最近错误信息`：可选
- 结果区：
  - 结论摘要
  - 推荐步骤（有序）
  - 自检清单（无序）
  - 故障诊断（仅排查模式）
  - 快捷动作按钮（回填字段/页面跳转）

## 3. 场景到动作映射
- `credential`：默认填充 Tushare base_url、跳转凭证页。
- `datasource`：默认预览代码、切换 POST 请求方法。
- `connection`：默认主机 localhost、默认端口 3306。
- `workflow`：跳转工作流页、打开工作流编辑器。

## 4. 状态与反馈
- 生成建议时显示全局 loading 文案：`AI 正在生成交互建议...`
- 事件埋点失败时静默，不阻断主流程。
- 字段未找到时给出明确提示：`未找到可操作字段`。

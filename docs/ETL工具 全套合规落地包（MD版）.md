# 二、软件激活授权机制设计（可直接开发落地）

## 1\. 授权模式

- 采用 \*\*机器码 \+ 激活码\*\* 绑定

- 机器码：读取设备CPU\+主板\+硬盘唯一标识，生成固定设备指纹

- 激活码：服务端生成加密串，绑定机器码、版本类型、到期时间

## 2\. 版本权限隔离

### （1）免费版

- 无激活也可永久使用

- 禁用：API接口、定时调度、预制模板、多任务并行

### （2）专业版（年付/永久）

- 绑定单设备/单内网

- 解锁：内网API、定时调度、增量同步、全部预制模板

- 限制：禁止集群多节点、无专属定制服务

### （3）企业版

- 支持多设备集群授权

- 解锁：多用户权限、集群部署、定制适配、专属运维通道

## 3\. 授权校验逻辑

1. 软件启动自动读取本地机器码

2. 比对本地授权文件加密信息

3. 校验不通过：自动降级为免费版，锁定付费功能

4. \*\*无任何强制联网校验\*\*（保护用户本地离线使用，合规不偷传数据）

5. 授权文件本地加密存储，防随意篡改

## 4\. 变现落地流程

用户付款 → 发给用户机器码 → 你后台生成激活码 → 用户填入软件激活 → 永久/周期解锁功能。

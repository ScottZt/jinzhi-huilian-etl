# Yahoo Finance 数据源配置教程 — 免费多市场行情数据

> **覆盖市场**: 美股、外汇、期货、加密货币、全球指数
> **费用**: 完全免费，无需 API Key
> **依赖**: `yfinance`

---

## 第一步：安装依赖

在金智汇联 ETL 后端环境中安装 yfinance：

```bash
cd backend
pip install yfinance
```

安装完成后验证：

```bash
python -c "import yfinance as yf; df = yf.Ticker('AAPL').history(period='5d'); print(df)"
```

如果输出了包含 Open/High/Low/Close/Volume 列的表格，说明安装成功。

---

## 第二步：配置数据源

在金智汇联 ETL 中操作：

1. 打开「数据源」页面，点击「新建数据源」
2. 选择 **📈 Yahoo Finance** 类型卡片
3. 填写配置：

| 字段 | 示例值 | 说明 |
|------|--------|------|
| 代码 | `AAPL` | 见下方各市场代码格式参考表 |
| K线周期 | `1d`（日线） | 可选: 1m/5m/15m/30m/1h/1d/1wk/1mo |
| 预览代码 | `AAPL` | 用于预览和测试的单只代码 |

4. 点击「测试连接」验证
5. 点击「预览K线样例」查看数据

## API 模板中心

在「API 模板中心」的 Yahoo tab 下，可直接点击「使用此接口」自动填充配置：

- **us_stock_daily**: 美股日线
- **forex_daily**: 外汇日线
- **crypto_daily**: 加密货币日线
- **futures_daily**: 期货日线
- **index_daily**: 指数日线

## 常见问题

**Q: 需要注册或 API Key 吗？**
A: 不需要。Yahoo Finance 是完全免费的数据源。

**Q: 数据是否有延迟？**
A: 股票和指数数据通常有 15 分钟延迟。外汇和加密货币数据基本实时。

**Q: 频率限制是什么？**
A: Yahoo Finance 没有官方 API 限制说明，但过于频繁的请求可能被临时封禁 IP。建议同步间隔不低于 1 分钟。

**Q: 中国 A 股能用 Yahoo Finance 吗？**
A: Yahoo Finance 对 A 股支持有限。推荐使用 AkShare 或 Tushare 获取 A 股数据。A 股的 Yahoo Symbol 格式为 `000001.SZ`（平安银行）、`600000.SS`（浦发银行）。

**Q: 历史数据能追溯到多远？**
A: 日线数据通常可追溯到股票上市以来。分钟线数据仅保留最近约 30 天。

**Q: 返回空数据怎么办？**
A: 检查 Symbol 是否正确。注意外汇必须加 `=X`，加密币必须加 `-USD`，期货必须加 `=F`，指数必须以 `^` 开头。

 ---
  配置步骤（以 Tushare Pro 为例）

  第一步：数据源连接（你已经完成测试连接）

  在「数据源」页面，新建数据源，选 HTTP REST，填入：

  ┌──────────────┬──────────────────────────────────────┐
  │     字段     │                示例值                │
  ├──────────────┼──────────────────────────────────────┤
  │ 名称         │ 我的Tushare                          │
  ├──────────────┼──────────────────────────────────────┤
  │ API 基础地址 │ https://api.tushare.pro              │
  ├──────────────┼──────────────────────────────────────┤
  │ HTTP 方法    │ POST                                 │
  ├──────────────┼──────────────────────────────────────┤
  │ 请求头       │ {"Content-Type": "application/json"} │
  └──────────────┴──────────────────────────────────────┘

  ▎ 注意：Tushare 的 token 不是在 headers 里传，而是在请求体里的。

  第二步：关键 — 配置请求体和响应解析

  这一步决定了能否 实际拉到数据：

  ┌──────────────┬───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
  │     字段     │                                                               示例值（Tushare daily 接口）                                                                │
  ├──────────────┼───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ 请求体模板   │ {"api_name": "daily", "token": "你的TOKEN", "params": {"ts_code": "", "start_date": "{start_time}", "end_date": "{end_time}"}, "fields":                  │
  │              │ "ts_code,trade_date,open,high,low,close,vol,amount"}                                                                                                      │
  ├──────────────┼───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ 响应数据路径 │ data.items                                                                                                                                                │
  ├──────────────┼───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ 时间字段名   │ trade_date                                                                                                                                                │
  ├──────────────┼───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ 字段映射     │ {"trade_date": "dt", "ts_code": "code", "open": "open", "high": "high", "low": "low", "close": "close", "vol": "vol", "amount": "amount"}                 │
  ├──────────────┼───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
  │ 预览股票代码 │ 000001.SZ（注意 Tushare 使用 .SZ/.SH 后缀）                                                                                                               │
  └──────────────┴───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘

  重点：request_template 里的变量 {start_time} 和 {end_time} 会被后端自动替换成日期字符串（默认格式 %Y%m%d）。

  第三步：保存 → 点击「预览数据」

  保存后，点击预览按钮，后端会：

  1. 从配置中取出 preview_codes（如 ["000001.SZ"]）
  2. 用 fetch_kline() 方法发实际 API 请求：
    - 将 request_template 中的 {start_time} 替换为 3 天前的日期
    - 将 {end_time} 替换为今天
    - 发起 POST 请求到 https://api.tushare.pro
  3. 按 response_data_path（data.items）从响应中提取数据列表
  4. 按 column_mapping 重命名字段
  5. 返回前 20 行数据展示

  ---
  为什么测试成功但预览没数据？

  常见原因：

  1. 请求体模板不对 — Tushare 的 token 必须在请求体的 token 字段里，不在 headers 里
  2. 股票代码格式不对 — Tushare 要求 000001.SZ 格式，不能只写 000001
  3. 响应路径不对 — 如果 response_data_path 写错了，后端无法从 Tushare 响应中提取到数据列表
  4. 接口权限 — Tushare 某些接口需要积分，低积分账户可能返回空数据

  ---
  完整的 request_template 示例（Tushare 日线行情）

  {
    "api_name": "daily",
    "token": "你在 tushare.pro 获取的 token",
    "params": {
      "ts_code": "",
      "start_date": "{start_time}",
      "end_date": "{end_time}"
    },
    "fields": "ts_code,trade_date,open,high,low,close,vol,amount"
  }

  Tushare 是 POST 一个 JSON 到同一个 base_url，用 api_name 字段来指定具体接口，这是它特有的设计。

金智汇连 ETL 工具分阶段产品需求文档（PRD）
文档说明
本文档围绕金融量化场景专属轻量化 ETL 工具核心定位，分三阶段制定产品迭代需求，明确各阶段目标、功能模块、详细需求、优先级、验收标准及风险管控
目标用户：个人量化交易者、中小量化团队、金融数据从业者
产品核心差异化：低代码可视化 + 量化原生功能 + AI 辅助 + 轻量化桌面端，区别于通用 ETL 工具，聚焦量化数据清洗、处理、回测适配全流程
一、产品整体定位
1. 核心定位
专为 A 股 / 期货量化交易打造的轻量化桌面端低代码 ETL 工具，解决量化从业者行情数据接入难、清洗繁琐、指标计算复杂、回测数据适配麻烦等痛点，实现数据一站式处理，开箱即用。
2. 核心价值
降低量化数据处理技术门槛，无需专业编程基础
聚焦量化场景，内置专属数据处理、指标计算、复权校准功能
AI 辅助快速生成处理流程，提升数据工作效率
轻量化部署，无复杂环境配置，适配个人 / 小团队使用
二、第一阶段：基础闭环打磨期（0-3 个月）
阶段目标
完成核心功能闭环，解决量化数据基础处理痛点，优化基础用户体验，实现数据接入 - 清洗处理 - 指标计算 - 数据落地全流程可用，达到产品可上线、用户可基础使用的标准。
1. 数据源管理模块
1.1 合规量化数据源接入
需求详情：内置 Tushare、AKShare、通达信 mootdx、期货 CTP 合规行情数据源接口；支持用户自定义 HTTP/API 数据源配置；提供数据源合规使用提示，明确数据使用边界
优先级：P0（最高）
验收标准：可正常连接各数据源，能筛选股票 / 期货标的、时间周期拉取数据；合规提示弹窗不可跳过，清晰标注数据仅限个人使用
交互要求：数据源配置界面简化，仅保留密钥、参数等必填项，一键测试连接
1.2 本地文件数据源
需求详情：支持 CSV/Excel/Parquet 量化数据文件批量导入，自动识别表头、数据格式
优先级：P0
验收标准：支持单文件 / 多文件导入，导入后可预览数据前 100 行，识别 K 线、标的代码等常规量化字段
2. 可视化工作流模块
2.1 基础数据处理节点
需求详情：新增缺失值填充、异常值剔除、重复数据删除、字段筛选 / 重命名基础清洗节点；支持节点拖拽、连线、参数配置
优先级：P0
验收标准：节点拖拽流畅，配置参数后可预览处理后数据，清洗逻辑生效无报错
2.2 量化核心基础节点
需求详情：实现股票前复权 / 后复权处理、涨跌停 / 停牌数据标记、日线 / 分钟线周期转换、简单均线指标计算
优先级：P0
验收标准：复权数据计算准确，周期转换无数据错乱，指标结果与主流行情软件一致
2.3 工作流基础操作
需求详情：支持工作流保存 / 加载、批量复制 / 删除节点、流程重置、单节点试运行
优先级：P1
验收标准：工作流本地保存无丢失，单节点运行可查看中间处理数据
3. 数据落地模块
3.1 存储格式适配
需求详情：支持导出为 CSV、Parquet、DuckDB、SQLite 轻量化存储格式；直接适配 Backtrader、VNPY 回测框架数据格式
优先级：P0
验收标准：导出文件可直接导入回测框架，无需二次修改格式
3.2 增量数据同步
需求详情：支持按时间戳增量更新数据，避免全量重复拉取
优先级：P1
验收标准：可设置增量更新时间节点，仅同步新增数据，不覆盖历史数据
4. AI 辅助模块
4.1 基础脚本生成
需求详情：根据用户简单文本指令，生成量化数据处理 Python 脚本；支持脚本复制、本地保存
优先级：P0
验收标准：生成脚本可直接运行，逻辑匹配用户需求，无语法错误
4.2 本地大模型适配
需求详情：支持接入 Ollama 本地大模型，保障用户数据隐私
优先级：P1
验收标准：配置本地模型端口后，可正常调用生成脚本，数据不上传云端
5. 用户体验优化
5.1 交互式新手引导
需求详情：首次启动引导用户完成 “数据源连接→搭建简单清洗流程→导出数据” 全流程，步骤化指引
优先级：P1
验收标准：新手可跟随引导在 5 分钟内完成一次完整数据处理操作
5.2 界面基础优化
需求详情：完善深色 / 浅色模式适配，优化界面布局，简化操作按钮；增加操作日志实时展示
优先级：P1
验收标准：两种模式界面无样式错乱，日志清晰标注操作步骤、报错信息
6. 阶段验收标准
核心功能无致命 BUG，数据处理准确率 100%
新手首次上手可独立完成基础数据处理流程
支持主流量化数据源、存储格式、回测框架适配
三、第二阶段：核心壁垒搭建期（3-6 个月）
阶段目标
强化量化场景专属功能，提升产品专业性与用户粘性，打通数据处理 - 策略回测前置 - 数据资产管理链路，解决用户进阶需求，形成产品核心竞争力。
1. 数据源模块升级
1.1 商用数据源拓展
需求详情：合规接入 Level2 行情、行业分类、概念板块、宏观经济辅助数据源；支持付费接入入口配置
优先级：P1
验收标准：可通过付费密钥连接，数据拉取稳定，无合规风险
1.2 数据质量校验
需求详情：新增数据完整性、准确性自动校验，缺失 K 线自动补全，异常数据告警
优先级：P0
验收标准：自动识别缺失 / 错误数据，提供一键修复选项，修复后数据无偏差
2. 可视化工作流进阶功能
2.1 量化指标库扩展
需求详情：新增 BOLL、KDJ、CCI、ATR 技术指标；新增动量、流动性、估值量化因子计算节点
优先级：P0
验收标准：指标 / 因子计算逻辑精准，支持自定义参数配置
2.2 标的池管理节点
需求详情：支持按行业、市值、成交额、涨跌幅批量筛选股票 / 期货标的，生成自定义标的池
优先级：P0
验收标准：多条件筛选逻辑准确，标的池可保存、复用至工作流
2.3 工作流模板库
需求详情：内置日线数据清洗、分钟线转日线、多因子数据生成、复权处理标准化模板
优先级：P0
验收标准：模板一键加载，简单修改参数即可使用，无需重新搭建流程
2.4 流程调试优化
需求详情：新增流程断点运行、中间数据导出、处理耗时统计功能
优先级：P1
验收标准：可精准定位流程报错节点，快速排查问题
3. 数据落地与调度模块
3.1 定时任务调度
需求详情：支持按交易日收盘后自动同步数据、自定义时间定时执行工作流
优先级：P0
验收标准：定时任务准时执行，执行完成 / 失败推送本地通知
3.2 批量数据处理
需求详情：支持多标的、多周期数据批量处理，提升大数据量处理效率
优先级：P1
验收标准：大数据量处理无卡顿、内存溢出，效率较单任务提升 50% 以上
4. AI 辅助模块升级
4.1 自然语言生成流程
需求详情：用户输入文字需求，自动生成可视化工作流，而非仅生成脚本
优先级：P0
验收标准：生成流程逻辑完整，可直接运行，匹配用户量化场景需求
4.2 场景化 AI 指令模板
需求详情：预设 AI 生成指令模板，用户只需填写参数即可快速生成流程 / 脚本
优先级：P1
验收标准：模板覆盖常用量化数据处理场景，调用便捷
5. 数据资产管理模块
5.1 数据资产目录
需求详情：统一管理本地数据源、工作流、处理后数据集，支持标签分类、搜索
优先级：P0
验收标准：资产快速检索，分类清晰，支持重命名、删除操作
5.2 数据血缘追踪
需求详情：可视化展示数据从接入到落地的全链路，回溯数据处理逻辑
优先级：P1
验收标准：清晰展示各节点处理关系，可查看每一步数据来源
6. 阶段验收标准
进阶量化功能完整，满足专业量化从业者需求
工作流模板、定时调度等功能大幅提升用户工作效率
大数据量处理性能稳定，无性能类 BUG
四、第三阶段：生态化商业化期（6 个月以上）
阶段目标
打造产品生态，拓展协作与增值功能，实现产品商业化变现，从单一工具升级为量化数据处理平台，提升产品长期生命力。
1. 插件化生态模块
1.1 自定义插件开发
需求详情：开放插件接口，支持用户用 Python 开发自定义数据源、处理节点、指标插件
优先级：P1
验收标准：插件打包、导入、运行流程简单，无兼容性问题
1.2 插件 / 模板市场
需求详情：搭建线上市场，用户可分享、下载免费 / 付费插件、工作流模板
优先级：P2
验收标准：市场内容可正常检索、下载，付费流程合规
2. 团队协作模块
2.1 多用户权限管理
优先级：P1
验收标准：支持管理员、普通用户角色分配，细化数据源、工作流读写权限
2.2 流程分享与协作
需求详情：支持工作流分享、团队内协作编辑、评论批注
优先级：P2
验收标准：分享流程可正常加载，协作编辑无冲突
3. 商业化增值模块
3.1 高级数据源订阅
需求详情：推出合规商用高频数据、研报数据、机构因子数据订阅服务
优先级：P1
验收标准：订阅流程清晰，付费后可正常使用专属数据源
3.2 企业版 / 私有部署
需求详情：推出团队企业版，支持私有部署、定制化功能开发、专属技术支持
优先级：P2
验收标准：满足企业级数据安全、私有化部署需求
3.3 标准化数据服务
需求详情：提供清洗完成的量化数据集订阅，用户直接下载使用
优先级：P2
验收标准：数据实时更新，格式标准，适配各类回测框架
4. 跨平台适配模块
需求详情：适配 macOS 系统，实现 Windows、macOS 双平台兼容
优先级：P1
验收标准：macOS 端功能与 Windows 端一致，运行流畅
5. 阶段验收标准
产品生态闭环，具备自我迭代、用户共建能力
商业化模式落地，实现稳定增值收益
覆盖个人、团队、企业三类用户需求
五、通用需求与风险管控
1. 通用需求
数据安全：用户 API 密钥、本地数据加密存储，所有数据处理本地运行，不上传第三方服务器
性能优化：优化大数据量处理内存占用，避免程序卡顿、崩溃
兼容性：适配 Windows10 及以上系统，支持主流电脑配置运行
2. 风险管控
合规风险：严格把控数据源合规性，明确告知用户数据使用范围，杜绝违规数据分发
性能风险：分阶段优化算法，逐步提升大数据处理能力，避免一次性迭代导致性能问题
用户体验风险：每阶段迭代后收集用户反馈，优先优化高频痛点问题，保持工具轻量化属性
六、迭代优先级说明
P0：必须实现，阶段核心功能，决定产品基础可用性
P1：重要功能，提升产品专业性与用户体验，需在阶段内完成
P2：优化 / 增值功能，不影响核心流程，可根据研发资源灵活调整

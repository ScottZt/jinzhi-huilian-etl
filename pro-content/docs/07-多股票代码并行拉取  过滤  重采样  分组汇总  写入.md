## 📋 示例7 详解：多股票代码并行拉取 → 过滤 → 重采样 → 分组汇总 → 写入

### 🎯 目标

测试并行拉取能力 + 完整 ETL 流程。

---

### 🔗 节点流程图

```
┌─ 并行拉取多股票 (source_fetch)
  ┌─ 过滤空值 (filter)
    ┌─ 重采样30分钟 (resample)
      ┌─ 分组汇总 (group_by)
        ┌─ 写入DuckDB (target_write)
```

---

### 📦 各节点详解

#### 1️⃣ n1: 并行拉取多股票

| 配置项 | 说明 |
|-------|------|
| 节点 ID | `n1` |
| 节点类型 | `source_fetch` |
| 功能 | 从数据源拉取原始数据 |
| 参数 | {"source_type": "mootdx", "source_config": "{}", "codes": "000001,600000,000002", "interval": "1min", "time_mode": "lookback", "lookback_days": 5, "parallel": true, "max_workers": 3, "session_only": t |

#### 2️⃣ n2: 过滤空值

| 配置项 | 说明 |
|-------|------|
| 节点 ID | `n2` |
| 节点类型 | `filter` |
| 功能 | 按条件过滤数据 |
| 参数 | {"mode": "keep", "conditions": [{"column": "close", "operator": "is_not_null", "value": ""}, {"column": "vol", "operator": "is_not_null", "value": ""}]} |

#### 3️⃣ n3: 重采样30分钟

| 配置项 | 说明 |
|-------|------|
| 节点 ID | `n3` |
| 节点类型 | `resample` |
| 功能 | 重采样（如 1 分钟→30 分钟） |
| 参数 | {"rule": "30min", "time_column": "dt", "group_column": "code"} |

#### 4️⃣ n4: 分组汇总

| 配置项 | 说明 |
|-------|------|
| 节点 ID | `n4` |
| 节点类型 | `group_by` |
| 功能 | 分组聚合 |
| 参数 | {"group_by": "code", "aggregations": "open=first,high=max,low=min,close=last,vol=sum"} |

#### 5️⃣ n5: 写入DuckDB

| 配置项 | 说明 |
|-------|------|
| 节点 ID | `n5` |
| 节点类型 | `target_write` |
| 功能 | 将处理结果写入目标库 |
| 参数 | {"target_type": "duckdb", "target_config": "{\"db_path\": \"D:/data/etl_output.db\"}", "target_table": "stock_30min_summary", "batch_size": 5000, "on_duplicate": "ignore", "columns": ""} |

---

### 💡 使用场景

本示例适用于需要**测试并行拉取能力 + 完整 ETL 流程。**的场景。

### ⚠️ 注意事项

1. 确保已配置对应的数据源连接
2. 根据实际数据调整参数配置
3. 大数据量时建议分批处理

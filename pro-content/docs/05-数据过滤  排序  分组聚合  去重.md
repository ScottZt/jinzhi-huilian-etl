## 📋 示例5 详解：数据过滤 + 排序 + 分组聚合 + 去重

### 🎯 目标

测试数据处理链路：过滤 → 排序 → 聚合 → 去重。

---

### 🔗 节点流程图

```
┌─ 过滤空成交量 (filter)
  ┌─ 按股票和时间排序 (sort)
    ┌─ 分组聚合 (group_by)
      ┌─ 按code去重 (dedup)
```

---

### 📦 各节点详解

#### 1️⃣ n1: 过滤空成交量

| 配置项 | 说明 |
|-------|------|
| 节点 ID | `n1` |
| 节点类型 | `filter` |
| 功能 | 按条件过滤数据 |
| 参数 | {"mode": "keep", "conditions": [{"column": "vol", "operator": "is_not_null", "value": ""}, {"column": "vol", "operator": ">", "value": 0}]} |

#### 2️⃣ n2: 按股票和时间排序

| 配置项 | 说明 |
|-------|------|
| 节点 ID | `n2` |
| 节点类型 | `sort` |
| 功能 | 排序 |
| 参数 | {"by": "code,dt", "ascending": true} |

#### 3️⃣ n3: 分组聚合

| 配置项 | 说明 |
|-------|------|
| 节点 ID | `n3` |
| 节点类型 | `group_by` |
| 功能 | 分组聚合 |
| 参数 | {"group_by": "code", "aggregations": "open=first,close=max,low=min,vol=sum"} |

#### 4️⃣ n4: 按code去重

| 配置项 | 说明 |
|-------|------|
| 节点 ID | `n4` |
| 节点类型 | `dedup` |
| 功能 | 去重 |
| 参数 | {"mode": "keep_last", "columns": "code", "target_type": "", "target_config": "{}", "target_table": "", "keep_existing_rows": "0"} |

---

### 💡 使用场景

本示例适用于需要**测试数据处理链路：过滤 → 排序 → 聚合 → 去重。**的场景。

### ⚠️ 注意事项

1. 确保已配置对应的数据源连接
2. 根据实际数据调整参数配置
3. 大数据量时建议分批处理

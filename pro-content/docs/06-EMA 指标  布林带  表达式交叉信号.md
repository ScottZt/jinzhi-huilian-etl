## 📋 示例6 详解：EMA 指标 + 布林带 + 表达式交叉信号

### 🎯 目标

测试 EMA + 布林带 + 自定义表达式组合策略信号。

---

### 🔗 节点流程图

```
┌─ EMA指标 (ma)
  ┌─ 布林带 (boll)
    ┌─ 交叉信号 (expression)
      ┌─ 突破上轨 (condition)
```

---

### 📦 各节点详解

#### 1️⃣ n1: EMA指标

| 配置项 | 说明 |
|-------|------|
| 节点 ID | `n1` |
| 节点类型 | `ma` |
| 功能 | 计算移动平均线（MA/EMA） |
| 参数 | {"windows": "12,26", "source_column": "close", "use_ema": true} |

#### 2️⃣ n2: 布林带

| 配置项 | 说明 |
|-------|------|
| 节点 ID | `n2` |
| 节点类型 | `boll` |
| 功能 | 计算布林带（BOLL） |
| 参数 | {"window": 20, "std_mult": 2, "source_column": "close"} |

#### 3️⃣ n3: 交叉信号

| 配置项 | 说明 |
|-------|------|
| 节点 ID | `n3` |
| 节点类型 | `expression` |
| 功能 | 表达式计算（自定义公式） |
| 参数 | {"target_column": "signal", "expression": "1 if df['ema_12'] > df['ema_26'] else -1"} |

#### 4️⃣ n4: 突破上轨

| 配置项 | 说明 |
|-------|------|
| 节点 ID | `n4` |
| 节点类型 | `condition` |
| 功能 | 条件分支（if/else） |
| 参数 | {"condition": "df['close'] > df['boll_upper']", "branch": "true"} |

---

### 💡 使用场景

本示例适用于需要**测试 EMA + 布林带 + 自定义表达式组合策略信号。**的场景。

### ⚠️ 注意事项

1. 确保已配置对应的数据源连接
2. 根据实际数据调整参数配置
3. 大数据量时建议分批处理
